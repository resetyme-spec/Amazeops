# 📋 Amaze Ops — Customer App REST API Specification

**Version:** 1.0.0 (Production)  
**Target Audience:** Customer-Facing Mobile & Web App Developers  
**Author:** Amaze Ops Engineering Team  

---

## 1. Overview & Architecture

The Customer App integrates with the Amaze Operations engine via REST API:
1. **Order Checkout:** When a customer books a laundry order, the Customer App pushes the order payload to `POST /api/orders`.
2. **Order Tracking:** The Customer App polls or queries `GET /api/orders/:order_no` to display live progress (In Washing, Quality Check, Out for Delivery, etc.).

---

## 2. Server Environments & Authentication

### Base URLs
* **Production URL:** `https://amaze-ops.web.app`
* **Local / Staging Test URL:** `http://localhost:3002`

### Security Headers
Every HTTP request must include the following headers:
```http
Content-Type: application/json
x-api-key: amaze-fab-super-admin-key-2026
```

## 3. API Endpoints

### 3.1 Push New Order (Checkout)
Pushes a customer order and garment list directly into the operations pipeline for automated dry-cleaner routing.

* **Method:** `POST`
* **Path:** `/api/orders`
* **Headers:**
  * `Content-Type: application/json`
  * `x-api-key: amaze-fab-super-admin-key-2026`

#### Request Body Schema (JSON)
```json
{
  "order_no": "ORD-1791437397061-2232",
  "customer_name": "Ramesh Kumar",
  "customer_phone": "+91 98765 43210",
  "customer_category": "Signature Care",
  "care_category": "Normal",
  "status": "RECEIVED",
  "created_at": "2026-10-26T12:00:00Z",
  "garments": [
    {
      "garment_id_code": "GAR-1791364294617-908",
      "qr_code": "QR-1791364294617",
      "garment_type": "SHIRT",
      "category": "GOLD",
      "service_type": "Wash & Iron"
    },
    {
      "garment_id_code": "GAR-1791364294617-909",
      "qr_code": "QR-1791364294617-2",
      "garment_type": "SAREE",
      "category": "GOLD",
      "service_type": "Dry Clean"
    },
    {
      "garment_id_code": "GAR-1791364294617-910",
      "qr_code": "QR-1791364294617-3",
      "garment_type": "TROUSER",
      "category": "BLUE",
      "service_type": "Iron Only"
    }
  ]
}
```

#### Field Definitions
| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `order_no` | string | **Yes** | Unique order reference generated by Customer App |
| `customer_name` | string | **Yes** | Client full name |
| `customer_phone` | string | **Yes** | Mobile number (used for SMS alerts & delivery calls) |
| `customer_category`| string | Optional | `Signature Care` (VIP), `Prime`, or `Regular` |
| `care_category` | string | Optional | Default `Normal` |
| `status` | string | **Yes** | Initial state (send `"RECEIVED"`) |
| `garments` | array | **Yes** | List of garments in the order |
| `garment_id_code` | string | **Yes** | Unique serial tag per item |
| `qr_code` | string | Optional | Physical barcode scanned on arrival |
| `garment_type` | string | **Yes** | e.g. `SHIRT`, `SAREE`, `SUIT`, `KURTA` |
| `category` | string | **Yes** | **Routing Driver**: `"GOLD"` (Delicate/Silk) or `"BLUE"` (Daily Cotton) |
| `service_type` | string | **Yes** | `Wash & Iron`, `Dry Clean`, or `Iron Only` |

#### Success Response (`201 Created`)
```json
{
  "success": true,
  "orderId": "ORD-1791437397061-2232",
  "message": "Order received and queued for partner assignment"
}
```

### 3.2 Get Live Order Status (Customer Tracking)
Queries real-time progress for a specific order.

* **Method:** `GET`
* **Path:** `/api/orders/:order_no`
* **Example:** `GET /api/orders/ORD-1791437397061-2232`
* **Headers:**
  * `x-api-key: amaze-fab-super-admin-key-2026`

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "order": {
    "orderId": "ORD-1791437397061-2232",
    "status": "IN_PROCESS",
    "deliveryStatus": "PENDING",
    "customer": {
      "name": "Ramesh Kumar",
      "phone": "+91 98765 43210",
      "category": "Signature Care"
    },
    "garments": [
      {
        "garmentId": "GAR-1791364294617-908",
        "garmentType": "SHIRT",
        "category": "GOLD",
        "serviceType": "Wash & Iron",
        "status": "IN_PROCESS"
      }
    ]
  }
}
```

## 4. Order Lifecycle & Status Progression Table

Map the returned `"status"` string to your Customer App tracking UI:

| Status Code | Customer App Display Label | Customer Description |
| :--- | :--- | :--- |
| `RECEIVED` | **Order Placed** | Order confirmed, scheduled for pickup |
| `ASSIGNED` | **Facility Allocated** | Clothes assigned to specialist care partner |
| `IN_PROCESS` | **Washing & Cleaning** | Dry cleaner has verified parcel and started processing |
| `QC_PENDING` | **Quality Checking** | Wash completed, undergoing stain & pressing inspection |
| `QC_APPROVED` | **Packed & Ready** | Certified 100% clean, bagged for dispatch |
| `READY_FOR_DELIVERY` | **Out for Delivery** | Handed over to delivery rider |
| `DELIVERED` | **Delivered ✓** | Parcel delivered to customer doorstep |
